# La Loma Cevichería Restobar

Carta digital responsiva de La Loma, con menú completo, navegación por categorías, carrito y envío del pedido por WhatsApp.

## Desarrollo local

```bash
npm install
npm run dev
```

## Compilación

```bash
npm run build
```

La salida de producción se genera en `dist/`.

## Despliegue en Cloudflare Pages

- Comando de compilación: `npm run build`
- Directorio de salida: `dist`
- Versión recomendada de Node.js: 20 o superior
